Enter the operator token

The token is the USAGE_REPORT_TOKEN secret on the project. It unlocks aggregate counters and nothing else. It is stored in this browser only, and every request goes straight to the usage Edge Function — the service key never reaches this page.

Regenerate or print it with npm run usage:token.

How to read this

  • Counters are client-reported. A browser with JavaScript disabled, or one blocking the project domain, is not counted at all.
  • Distinct browsers means distinct browsers, not people: one player on two devices counts twice, and clearing site data starts a new one.
  • Do Not Track and Global Privacy Control are honored, so those visitors opt out entirely and the totals undercount by an unknown amount.
  • Temporary modes — jukebox, shop, custom Cubie, and the block guide — never start a run, so they produce visits but no plays.
  • A hostile client can inflate counters but cannot read them. If totals run far above distinct browsers, treat the numbers as a trend, not a measurement.

The command line reads the same document: npm run usage:report -- --days 30.
